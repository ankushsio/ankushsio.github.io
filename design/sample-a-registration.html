Clinical Trial Management Platform

Connecting trial study teams and participants to hospital record systems.

Trial data lives inside hospital EHR systems that each expose different APIs, standards and quirks, so every new data source risked becoming a bespoke integration. I built the integration hub's base adapter modules so that each new EHR connection follows one predictable shape, then wrote the first adapter as the reference the others were built from.

The platform also handled patient data without a real access-control story. I designed and shipped role-based access across both applications — admin-only endpoint restriction, per-role response filtering, and pre-authorization checks for resources a user cannot reach.

Deploy pipeline 26m 33s → 18m 07s. Service image 450 MB → 290 MB. Idle cloud spend caught and stopped, $200+ saved.

AR Surgical Navigation

Reconstructing 3D anatomy from intra-operative video.

The reconstruction pipeline wrote intermediate results to disk between every stage, which made it slow and brittle. Worse, a signed distance field computation ran per frame and dominated the budget — no amount of tuning elsewhere mattered while it sat there.

I migrated the pipeline to in-memory, which meant understanding every module's inputs and outputs and refactoring the seams between them. Then I worked out that the distance field did not need recomputing per frame at all, and devised a way to compute it once and reuse it.

Removed the dominant per-frame cost — over 80% of the time it consumed.
