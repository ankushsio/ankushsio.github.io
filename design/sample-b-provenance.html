Clinical Trial Management Platform

2024 – present · Clinical research

Trial data lives inside hospital EHR systems that each expose different APIs and standards, so every new source risked becoming a bespoke integration. I built the integration hub’s base adapter modules so each new connection follows one predictable shape, then wrote the reference adapter the others were built from.

The platform also handled patient data without a real access-control story. I designed and shipped role-based access across both applications — admin-only endpoint restriction, per-role response filtering, and pre-authorization checks.
